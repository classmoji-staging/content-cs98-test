precedence and cascading

more specific selector with more classes wins

more specific wins regardless of order

!important gets the highest precedence (use sparingly!)

inline styles have second highest precedence (bad: hard to override)

ok, how do we position something on a page?

Default. Elements take up space within the document flow.

No properties like top, right, bottom, left take effect.

position: static;

Nudged from where it would normally sit, via top, right, bottom, left. Its original space is still reserved.

position: relative;

Position is relative to the nearest positioned ancestor (anything but static) via top, right, bottom, left.

Element is removed from flow so other elements ignore it.

position: absolute;

Position is relative to the window via top, right, bottom, left properties.

Otherwise similar to absolute. Position 0,0 is the top left corner.

position: fixed;

.nav {

position: sticky;

top: 0;

}

Sits in normal flow until it would scroll past the offset you gave it — then it stops and stays. Needs a top, right, bottom or left to stick to.

position: sticky;

Layers any positioned element (relative, absolute, fixed, sticky) — and flex/grid children. Parameter: signed integer. stacking contexts

transitions model

property: (required) of the element to apply to. can be specific property like background-color, a list, or all.

duration: (required) timespan in milliseconds or seconds units that the effect lasts.

timing-function: (optional) animation interpolation type: linear, ease (default), ease-in, ease-out, ease-in-out, even cubic-bezier.

delay: (optional) delay before the start of the animation in milliseconds or seconds units.
